Carrico Recipe Microsite
========================

I want to build a small static microsite that has all of my favorite recipies stored.  It will be hosted in some static site location upon build.

# Technical

* Node.js (latest with long term support)
* Sass (no design frameworks like Bootstrap)
* Industry best practices should always be observed

# Features

* Each recipe should be a markdown file, with relavant metadata stored up top
* For the frontend, I should be able to search the cards or filter by tags on the frontend.
* When looking at a recipe, I should be able to toggle the resulting amount (e.g., I can 2x the recipe output if I want)
* There should be a script to be able to migrate a recipe from Paprika to turn it into a card on my site (see _sample_data/)
* Design should be modern and bright
